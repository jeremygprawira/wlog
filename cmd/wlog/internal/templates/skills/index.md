# wlog skills

One folder per skill, with the skill itself in `SKILL.md`. The `wlog agents` command
installs the same three skills into a project.

| Skill | What it does |
|---|---|
| [instrument-with-wlog](instrument-with-wlog/SKILL.md) | Add one wide event to a Go handler or job, with the field naming rules. |
| [audit-a-handler](audit-a-handler/SKILL.md) | Record who did what, to which target, with an outcome, through audit.Do. |
| [analyze-wlog-output](analyze-wlog-output/SKILL.md) | Search the events with wlog query and read one event's shape. |
